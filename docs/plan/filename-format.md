# 时间戳文件名与移动工具栏优化计划

## 目标

将新笔记文件名从 `yyyyMMddHHmmss.md` 改为 `yyyyMMdd-HHmmss.md`，例如 `20260921-232810.md`。短横线位于“日”和“时”之间，时间仍使用上海时区并精确到秒。

## 范围

- 修改服务端文件名生成函数。
- 更新同秒冲突顺延逻辑的单元测试、真实浏览器断言和生产验收脚本。
- 更新 README、规则与部署事实文档中的格式说明。
- 保持内部 UUID、版本控制、手动上传、GitHub 投递和服务器清理行为不变。

## 移动工具栏交互

- 仅调整右侧编辑格式工具栏，底部导航栏保持原位。
- 手机端默认收起完整格式工具栏，只显示右侧 44×44px 的小悬浮按钮。
- 点击悬浮按钮展开现有完整格式工具栏；再次点击按钮、点击工具栏外部或按 Escape 时收起。
- 点击格式命令后保持展开，便于连续使用；用户主动收起后记住该浏览器的选择。
- 展开时继续使用当前 52px 宽竖向栏和至少 44px 的触控目标，不遮挡底部导航、系统安全区或正文主要输入区域。
- 悬浮按钮使用 Obsidian 自带图标、主题变量和焦点样式，不引入新的图像资产。

## 兼容策略

- 只影响切换后新建的笔记。
- 不重命名 GitHub、电脑仓库或服务器队列中的历史文件，避免制造无意义的移动提交和旧会话冲突。
- 生产核验工具同时接受旧格式历史记录与新格式，但新建笔记测试必须断言新格式。

## 验收

- 固定时间 `2026-09-20T06:30:52.000Z` 生成 `20260920-143052.md`。
- 同一秒创建多篇时继续按秒顺延，且短横线位置不变。
- 17 项应用测试、10 项真实浏览器测试和构建通过。
- 部署后新会话文件名匹配 `^\d{8}-\d{6}\.md$`，页面、WebSocket、手动上传与 GitHub worker 保持正常。
- 真实手机视口下工具栏默认只显示悬浮按钮；按钮可展开和收起完整工具栏，状态恢复后正文和光标不变化。
